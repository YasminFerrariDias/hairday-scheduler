# HairDay Scheduler

Sistema de agendamento de horários desenvolvido em JavaScript, com organização modular, manipulação do DOM e integração com serviços.

## Tecnologias

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) — estruturação da página
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — estilização e layout
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) — lógica e manipulação do DOM
- [Webpack](https://webpack.js.org/) — bundler e organização modular

## Funcionalidades

- Seleção de data para agendamento
- Escolha de horários disponíveis por período (manhã, tarde e noite)
- Cadastro de cliente e criação de agendamentos
- Listagem e cancelamento de agendamentos
- Atualização dinâmica da interface

## Como Executar

```bash
npm install
npm run dev
```

## Sobre

Projeto desenvolvido durante um curso, onde a estrutura base (HTML e CSS) foi fornecida. A lógica, organização modular e funcionalidades em JavaScript foram implementadas por mim como parte do aprendizado.
